# E2E Tests Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add e2e tests that validate CrashLoopBackOff, Unschedulable, and OOMKilled detection against a real K3s cluster.

**Architecture:** K3s via Testcontainers provides the cluster, operator runs in-process via JOSDK's `LocallyRunOperatorExtension`, WireMock captures webhook calls. Tests create problematic pods and assert webhook was called with correct data and PodWatcher status was updated.

**Tech Stack:** JUnit 5, Testcontainers (k3s module), WireMock, Awaitility, JOSDK junit5 extension

---

## File Structure

- `pom.xml` — add test dependencies + Maven Failsafe plugin with `e2e` profile
- `src/test/java/io/crashnotifier/e2e/E2ETestBase.java` — shared setup (K3s, client, WireMock, operator extension)
- `src/test/java/io/crashnotifier/e2e/PodCrashE2ETest.java` — 3 test scenarios
- `run.sh` — add `e2e` command

### Task 2: Create E2ETestBase

**Files:**
- Create: `src/test/java/io/crashnotifier/e2e/E2ETestBase.java`

- [ ] **Step 1: Create the base test class**

```java
package io.crashnotifier.e2e;

import com.github.tomakehurst.wiremock.junit5.WireMockExtension;
import io.crashnotifier.crd.*;
import io.crashnotifier.reconciler.PodWatcherReconciler;
import io.crashnotifier.scheduler.AlertResetScheduler;
import io.fabric8.kubernetes.client.Config;
import io.fabric8.kubernetes.client.KubernetesClient;
import io.fabric8.kubernetes.client.KubernetesClientBuilder;
import io.javaoperatorsdk.operator.junit.LocallyRunOperatorExtension;
import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.extension.RegisterExtension;
import org.testcontainers.k3s.K3sContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;
import org.testcontainers.utility.DockerImageName;

import static com.github.tomakehurst.wiremock.core.WireMockConfiguration.wireMockConfig;
import static com.github.tomakehurst.wiremock.client.WireMock.*;

@Testcontainers
public abstract class E2ETestBase {

    @Container
    static K3sContainer k3s = new K3sContainer(DockerImageName.parse("rancher/k3s:v1.30.4-k3s1"));

    @RegisterExtension
    static WireMockExtension wireMock = WireMockExtension.newInstance()
            .options(wireMockConfig().dynamicPort())
            .build();

    protected static KubernetesClient client;
    protected static LocallyRunOperatorExtension operator;
    protected String testNamespace;

    @BeforeEach
    void setUp() {
        // Create client from K3s kubeconfig
        String kubeconfig = k3s.getKubeConfigYaml();
        Config config = Config.fromKubeconfig(kubeconfig);
        client = new KubernetesClientBuilder().withConfig(config).build();

        // Create isolated namespace
        testNamespace = "e2e-test-" + System.currentTimeMillis();
        client.namespaces().resource(
                new io.fabric8.kubernetes.api.model.NamespaceBuilder()
                        .withNewMetadata().withName(testNamespace).endMetadata().build()
        ).create();

        // Apply CRD
        var crdYaml = client.load(getClass().getResourceAsStream("/META-INF/fabric8/podwatchers.crash-notifier.io-v1.yml"));
        crdYaml.create();

        // Start operator
        AlertResetScheduler scheduler = new AlertResetScheduler(client);
        PodWatcherReconciler reconciler = new PodWatcherReconciler(scheduler);
        operator = LocallyRunOperatorExtension.builder()
                .withReconciler(reconciler)
                .withKubernetesClient(client)
                .build();

        // Stub WireMock to accept any POST
        wireMock.stubFor(post(urlEqualTo("/webhook"))
                .willReturn(aResponse().withStatus(200)));
    }

    @AfterEach
    void tearDown() {
        if (client != null && testNamespace != null) {
            client.namespaces().withName(testNamespace).delete();
        }
    }

    protected PodWatcher createPodWatcher(DetectionConfig detections) {
        PodWatcher pw = new PodWatcher();
        pw.getMetadata().setName("test-watcher");
        pw.getMetadata().setNamespace(testNamespace);

        PodWatcherSpec spec = new PodWatcherSpec();
        WebhookConfig webhook = new WebhookConfig();
        webhook.setUrl(wireMock.baseUrl() + "/webhook");
        spec.setWebhook(webhook);
        spec.setDetections(detections != null ? detections : new DetectionConfig());
        pw.setSpec(spec);

        return client.resource(pw).inNamespace(testNamespace).create();
    }
}
```

NOTE: The exact setup for `LocallyRunOperatorExtension` may need adjustment based on the JOSDK 5.0.1 API. The extension might need to be a `@RegisterExtension` field built differently. Check compilation and adjust. The key requirement is: operator runs in-process, connected to the K3s cluster.

### Task 3: Create PodCrashE2ETest

**Files:**
- Create: `src/test/java/io/crashnotifier/e2e/PodCrashE2ETest.java`

- [ ] **Step 1: Create the test class with 3 scenarios**

```java
package io.crashnotifier.e2e;

import com.github.tomakehurst.wiremock.client.WireMock;
import io.crashnotifier.crd.DetectionConfig;
import io.crashnotifier.crd.PodWatcher;
import io.fabric8.kubernetes.api.model.*;
import org.junit.jupiter.api.Test;

import java.time.Duration;
import java.util.List;
import java.util.Map;

import static com.github.tomakehurst.wiremock.client.WireMock.*;
import static org.awaitility.Awaitility.await;
import static org.junit.jupiter.api.Assertions.*;

class PodCrashE2ETest extends E2ETestBase {

    @Test
    void detectsCrashLoopBackOffWithEventsAndLogs() {
        // Setup
        createPodWatcher(null);
        createCrashingPod("crash-pod");

        // Wait for webhook to be called
        await().atMost(Duration.ofSeconds(120)).pollInterval(Duration.ofSeconds(5)).untilAsserted(() -> {
            wireMock.verify(postRequestedFor(urlEqualTo("/webhook"))
                    .withRequestBody(containing("CrashLoopBackOff"))
                    .withRequestBody(containing("crash-pod")));
        });

        // Verify events and logs are present in the webhook body
        var requests = wireMock.findAll(postRequestedFor(urlEqualTo("/webhook")));
        assertFalse(requests.isEmpty());
        String body = requests.get(0).getBodyAsString();
        assertTrue(body.contains("app starting"), "Should contain logs from terminated container");
        assertTrue(body.contains("events") && !body.contains("\"events\":\"\""),
                "Should contain non-empty events");

        // Verify PodWatcher status updated
        await().atMost(Duration.ofSeconds(30)).untilAsserted(() -> {
            PodWatcher pw = client.resources(PodWatcher.class)
                    .inNamespace(testNamespace).withName("test-watcher").get();
            assertNotNull(pw.getStatus());
            assertTrue(pw.getStatus().getAlertedPods().stream()
                    .anyMatch(a -> "crash-pod".equals(a.getPodName())));
        });

        // Verify dedup: reset wiremock, wait, no new calls
        wireMock.resetRequests();
        await().during(Duration.ofSeconds(30)).atMost(Duration.ofSeconds(35)).untilAsserted(() -> {
            wireMock.verify(0, postRequestedFor(urlEqualTo("/webhook")));
        });
    }

    @Test
    void detectsUnschedulablePod() {
        // Setup with low pending threshold
        DetectionConfig config = new DetectionConfig();
        config.setPendingThresholdSeconds(10);
        createPodWatcher(config);
        createUnschedulablePod("pending-pod");

        // Wait for webhook
        await().atMost(Duration.ofSeconds(60)).pollInterval(Duration.ofSeconds(5)).untilAsserted(() -> {
            wireMock.verify(postRequestedFor(urlEqualTo("/webhook"))
                    .withRequestBody(containing("Unschedulable"))
                    .withRequestBody(containing("pending-pod")));
        });

        // Verify status
        await().atMost(Duration.ofSeconds(30)).untilAsserted(() -> {
            PodWatcher pw = client.resources(PodWatcher.class)
                    .inNamespace(testNamespace).withName("test-watcher").get();
            assertNotNull(pw.getStatus());
            assertTrue(pw.getStatus().getAlertedPods().stream()
                    .anyMatch(a -> "pending-pod".equals(a.getPodName())));
        });
    }

    @Test
    void detectsOOMKilled() {
        createPodWatcher(null);
        createOOMPod("oom-pod");

        // Wait for webhook (OOM may take a while)
        await().atMost(Duration.ofSeconds(120)).pollInterval(Duration.ofSeconds(5)).untilAsserted(() -> {
            wireMock.verify(postRequestedFor(urlEqualTo("/webhook"))
                    .withRequestBody(containing("OOMKilled"))
                    .withRequestBody(containing("oom-pod")));
        });

        // Verify status
        await().atMost(Duration.ofSeconds(30)).untilAsserted(() -> {
            PodWatcher pw = client.resources(PodWatcher.class)
                    .inNamespace(testNamespace).withName("test-watcher").get();
            assertNotNull(pw.getStatus());
            assertTrue(pw.getStatus().getAlertedPods().stream()
                    .anyMatch(a -> "oom-pod".equals(a.getPodName())));
        });
    }

    // --- Pod Factories ---

    private void createCrashingPod(String name) {
        Pod pod = new PodBuilder()
                .withNewMetadata().withName(name).withNamespace(testNamespace).endMetadata()
                .withNewSpec()
                .addNewContainer()
                .withName("app")
                .withImage("busybox:latest")
                .withCommand("sh", "-c", "echo 'app starting'; exit 1")
                .endContainer()
                .withRestartPolicy("Always")
                .endSpec()
                .build();
        client.pods().inNamespace(testNamespace).resource(pod).create();
    }

    private void createUnschedulablePod(String name) {
        Pod pod = new PodBuilder()
                .withNewMetadata().withName(name).withNamespace(testNamespace).endMetadata()
                .withNewSpec()
                .addNewContainer()
                .withName("app")
                .withImage("busybox:latest")
                .withCommand("sleep", "3600")
                .withNewResources()
                .addToRequests("memory", new Quantity("999Gi"))
                .endResources()
                .endContainer()
                .endSpec()
                .build();
        client.pods().inNamespace(testNamespace).resource(pod).create();
    }

    private void createOOMPod(String name) {
        Pod pod = new PodBuilder()
                .withNewMetadata().withName(name).withNamespace(testNamespace).endMetadata()
                .withNewSpec()
                .addNewContainer()
                .withName("app")
                .withImage("busybox:latest")
                .withCommand("sh", "-c", "echo 'allocating memory'; head -c 100m /dev/urandom > /dev/null; sleep 60")
                .withNewResources()
                .addToLimits("memory", new Quantity("10Mi"))
                .endResources()
                .endContainer()
                .withRestartPolicy("Always")
                .endSpec()
                .build();
        client.pods().inNamespace(testNamespace).resource(pod).create();
    }
}
```
